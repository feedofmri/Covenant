## The headline

**A stolen agent key can only pay your own family.** The agent's key can call four kinds of function on the `PolicyVault`: pay a *registered* payee, move money between internal buckets, swap or lend with the vault itself as the hard-coded recipient, and propose a payment for the owner to co-sign. There is no generic call path. Every recipient comes from an owner-controlled payee registry, every payment counts against per-payment and 24-hour caps, and anything above the co-sign ceiling reverts.

The second direction of the guardrail protects the user from human scammers: new payees cool off for 24 hours, the first payment to anyone needs the owner's signature, scam patterns hold a request and alert the guardian, and even the owner's own withdrawals to unknown addresses wait out the cooling-off.

## Topic F operations

| Operation | What Covenant does | Where |
| --- | --- | --- |
| Asset management | Splits wages into family / emergency / savings buckets by the mandate; lends idle savings within an exposure cap; swaps with an oracle floor | `allocate`, `supply`, `withdraw`, `swap` |
| Transaction execution | Scheduled remittances, owner requests in chat (English and Bangla), co-signed payments above the cap | `pay`, `propose` → `approve` / `approveWithSig` |
| Risk control | Four-tier permission model in Solidity, 15 deterministic risk rules, pre-trade simulation, post-trade verification with circuit breaker, peg monitor, sanctions denylist, scam scoring | `PolicyVault`, `agent/src/risk/` |

## Quick start (local, 2 minutes)

Requirements: Node 22. No compiler download is needed (the Solidity compiler ships with npm).

```bash
npm install
npm run stack            # local chain + deploy + server (http://127.0.0.1:8787) + web (http://127.0.0.1:5173)
# in a second terminal:
npm run demo             # runs D1–D9 end to end and writes evidence/localhost/ledger.md
npm run redteam          # 30 attack cases → redteam/RESULTS.localhost.md
```

To use the web app as the owner, import Hardhat dev account #1 (`0x7099…79C8`, a public test key) into MetaMask on the local network (chain 31337, RPC `http://127.0.0.1:8545`). The guardian is account #2.

Without a model key the agent uses its deterministic offline planner. Set `ANTHROPIC_API_KEY` to plan with Claude; every plan goes through the same checks either way.

Docker alternative: `docker compose up --build`.

## Tests

```bash
npm run test:contracts   # 38 unit tests + invariant harness (INVARIANT_RUNS=300 INVARIANT_STEPS=60 for the long run)
npm run coverage         # solidity-coverage; scripts/coverage-gate.js enforces ≥ 95 % lines on production contracts
npm -w agent test        # 32 tests: unit, Claude adapter against a fake API, end-to-end (need: npm run node && npm run deploy:local)
npm -w server test       # 21 tests: API and auth, Telegram bot, system test, unattended run
npm run lint && npm run licenses
```

CI (`.github/workflows/ci.yml`) runs lint, licence check, contract tests with coverage gate, Slither, a full end-to-end job (chain → deploy → agent/server tests → D1–D9 → red-team) and the web build.

## Deploy to Base Sepolia

See [docs/deployment.md](docs/deployment.md): fill `.env` from `.env.example`, `npm run deploy:base-sepolia`, start the server (Docker image includes anvil for fork simulation), run `npm run demo` and `npm run redteam` with `DEPLOYMENT=baseSepolia` to produce the public hash ledger.

## Honest limitations

The prototype runs on a public testnet with **clearly labelled mocks** for the stablecoins, price feeds, AMM pool and lending market (`contracts/src/mocks`, each exposing `isMock()`). Cash-out to local currency is out of scope and would go through licensed partners. Production would run only on rails a jurisdiction permits (licensed stablecoins or bank-issued tokenized deposits). The full known-risk list is in [docs/known-risks.md](docs/known-risks.md).
